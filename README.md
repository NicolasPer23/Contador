# Contador - Programação Mobile 

# Como Funciona

O Contador inicia no valor 0, o botão de subtrair fica desabilitado, pois coloquei um boolean onde o valor tem que ser maior que zero para habilita-lo.
Existe 3 opções de botões:
- +Somar - Acrescenta 1 no valor atual todo clique.
- -Substrair - Substrai 1 no valor atual todo clique.
- Zerar - Muda o valor atual para 0.

# Tecnologias usadas

- Kotlin
- Android Studio
- Jetpack Compose
- Material 3
